# Benchmarking Virtual Screening Workflows for SARS-CoV-2 NSP14 N7-Methyltransferase: Target-Specific Machine Learning Re-Scoring Improves Retrospective Enrichment of Bisubstrate Inhibitors

This repository provides top-performing, target-specific Machine Learning Scoring Functions (MLSFs) for the virtual screening of SARS-CoV-2 NSP14 N7-methyltransferase (MTase) bisubstrate inhibitors. It includes both structure-based (docking-dependent PLEC) and ligand-based (docking-free ECFP4) models, alongside a curated dataset of actives, true inactives, and decoys, as described in our study:

## Dataset

The `dataset/` directory contains literature-curated actives and true inactives, plus property-matched decoys generated with DeepCoy (pretrained to match DEKOIS 2.0 physicochemical criteria). It is provided for reproducibility and further method development.
In addition, the repository includes the train-test split used for model development and evaluation.

| Folder | Files | Description |
|---|---|---|
| `dataset/full_sets/` | `Actives.csv`, `TrueInactives.csv`, `Decoys.csv` | Complete compound sets, one file per class. |
| `dataset/train_test_split/` | `test_mol_names.txt`, `train_mol_names.txt` | Training and test sets used for model development and benchmarking. |

## Models
The model development and evaluation workflow was adapted, with modifications, from the protocol described by [Tran-Nguyen et al. (2023)](https://doi.org/10.1038/s41596-023-00885-w).

The `models/` directory contains eight pre-trained models, each combining an SVM or XGBoost algorithm with a specific feature representation. 

- **The docking-free models** use 2048-bit ECFP4 fingerprints calculated directly from ligand structures, enabling activity prediction without docking or receptor information.
- **The docking-based models** use 4096-bit PLEC fingerprints derived from binding poses generated by PLANTS, Smina, or FRED and are designed for pose re-scoring. 

The available model files are listed below:

| Feature Source | XGBoost Model | SVM Model | NEF1% (SVM / XGB) | pROC-AUC (SVM / XGB) |
|---|---|---|---|---|
| ECFP4 fingerprints (docking-free) | `NSP14-XGB-ECFP4.json` | `NSP14-SVM-ECFP4.joblib` | **0.746 / 0.761** | **1.68 / 1.78** |
| PLANTS-derived PLEC fingerprints | `NSP14-XGB-PLANTS.json` | `NSP14-SVM-PLANTS.joblib` |**0.702 / 0.687**| **1.63 / 1.61** |
| Smina-derived PLEC fingerprints | `NSP14-XGB-Smina.json` | `NSP14-SVM-Smina.joblib` | **0.702 / 0.672** | **1.55 / 1.62** |
| FRED-derived PLEC fingerprints | `NSP14-XGB-FRED.json` | `NSP14-SVM-FRED.joblib` | **0.702 / 0.702** | **1.53 / 1.61** |


## Installation
Use the provided Conda environment (Miniconda or Anaconda required) to avoid dependency conflicts:

```bash
git clone <repository-url>
cd <repository-directory>
conda env create -f environment.yml
conda activate plec_prediction
```

## How to Use

The pipeline has three steps: docking, fingerprints generation, and activity prediction. 

### Step 1: Docking (PLEC models only)

1. Dock the prepared ligands against the prepared NSP14 MTase structure (PDB ID: 9R5T) provided in `/example` folder using PLANTS, FRED, or Smina.

2. Extract the top-ranked pose for each ligand and combine them into a single `.mol2` file.
### Step 2: Generate fingerprints

Run `python scripts/01_generate_fingerprints.py` for interactive prompts, or pass options directly.

**ECFP4** (compounds only; `.mol2`, `.sdf` or `.smi`):

```bash
python scripts/01_generate_fingerprints.py --type ecfp4 \
    --mol_path compounds.sdf \
    --output_csv ecfp4_features.csv
```

**PLEC** (docked compounds + receptor, both `.mol2`):

```bash
python scripts/01_generate_fingerprints.py --type plec \
    --mol_path example/compounds/plants-docked-compounds.mol2 \
    --receptor_path example/NSP14-9R5T.mol2 \
    --output_csv example/features/plants_plec_features.csv
```

Optional: `--n_jobs` (CPU cores; default half your cores), `--verbose`.

### Step 3: Predict activity

Run `python scripts/02_predict_activity.py` for interactive model selection (lists `models/`), or pass options directly:

```bash
python scripts/02_predict_activity.py \
    --model_path models/NSP14-SVM-PLANTS.joblib \
    --features_csv example/features/plants_plec_features.csv \
    --output_results example/predictions/plants_plec_svm_predictions.csv
```
Optional: 
- `--n_jobs` (CPU cores; default half your cores, auto-skipped for single-threaded models like SVM), 
- `--verbose`.

### Example

The `example/` folder is organized into three subfolders and the NSP14 receptor file::

- `example/compounds/`: the input compounds used to generate fingerprints. 
- `example/features/`: the generated fingerprints. 
- `example/predictions/`: the predicted activities.
- `example/NSP14-9R5T.mol2`:  the prepared NSP14 MTase receptor (PDB ID: 9R5T) used in this study and the provided Example.

### Notes
- The file paths and names in the commands are provided as examples. Please replace them with the actual paths and filenames of your own dataset. 
- **The model must match its features.** Re-score poses with the model trained on the same docking tool (PLANTS poses → PLANTS model, etc.). Don't mix feature types or docking tools (e.g. FRED poses with a PLANTS model, or ECFP4 features with a PLEC model): predictions will be unreliable or fail with a feature-count error.
- **Compound names** come from molecule titles in the input file; missing titles become `mol_0`, `mol_1`, etc.
